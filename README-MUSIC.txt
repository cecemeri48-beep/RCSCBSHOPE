MUSIK SLIDESHOW — 3 LAGU

Lagu berikut dilindungi hak cipta sehingga file audionya tidak disertakan:
1. My Way — Frank Sinatra
2. Wish You Were Here — Pink Floyd
3. Lingkaran Aku Cinta Padamu — Sirkus Barock
   Spotify: https://open.spotify.com/intl-id/track/7t3uuzZvbwZzBQEHFgASZz

Agar musik otomatis diputar setelah pengguna mengetuk foto:
1. Siapkan ketiga MP3 dari sumber yang legal.
2. Ubah nama file menjadi persis:
   - my-way.mp3
   - wish-you-were-here.mp3
   - lingkaran-aku-cinta-padamu.mp3
3. Letakkan ketiganya di root proyek, sejajar dengan album.html.
4. Push/redeploy kembali.

Slideshow akan memulai lagu yang dipilih dan otomatis berpindah ke lagu
berikutnya setelah lagu selesai. Pengguna juga dapat memilih lagu dari kontrol
slideshow. Jika file belum tersedia, slideshow foto tetap berjalan.
